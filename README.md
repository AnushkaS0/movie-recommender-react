# 🎬 Movie Recommendation Web App

A simple and visually appealing web app built with **React** (Frontend) and **Node.js + Express** (Backend) that allows users to:
- Search for movies
- Get recommendations based on mood
- Receive suggestions based on previously watched movies

---

## Features

- Search bar to filter movies by title
- Mood-based movie recommendations
- Recommendations based on watch history
- Styled with CSS for a clean, modern look
- Frontend–Backend interaction via Express API
- Easily extendable with databases or authentication
